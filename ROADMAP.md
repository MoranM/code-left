# Roadmap

This roadmap describes the intended growth of the Code-Left repository.

## Phase 1 - Setup foundation

Status: in progress

- Simple first-use path.
- Engineering and product adoption tracks.
- Engineering starter templates.
- Agent-neutral terminology.

## Phase 2 - Repo trust and visual clarity

Status: in progress

- Community contribution files.
- GitHub issue and pull request templates.
- Documentation checks.
- Mermaid diagrams for the operating model and adoption flow.

## Phase 3 - Example and setup skill

Status: in progress

- Add a complete first-pilot example.
- Create a skill that guides a team through Code-Left setup.
- Orchestrate readiness assessment, integration-point selection, playbook creation, and pilot packaging.
- Keep the workflow agent-neutral and repo-portable.

## Phase 4 - Worked examples

Status: planned

- Add more examples by change type.
- Show product and engineering variants for common workflows.
- Include examples of playbook improvement after review.

## Phase 5 - Tool adapters

Status: planned

- Add optional setup notes for specific agent tools.
- Keep core docs portable.
- Put tool-specific paths and conventions in adapter docs rather than the main model.
